# 自定义仪表盘（布局协议 v1）

2026-11-11。手机 App 的本地外观功能，仍使用 Flutter 原生画布和现有 UDP/导航数据，无 AI API、脚本解释器或新增联网端点。

## 使用

仪表盘 → 自定义仪表盘 → 新增。复制 AI 提示词，追加希望的赛车 DDU 外观，交给任意 AI；粘贴返回的 JSON，点击「检查并预览」，确认后保存。AI 输出可能需要修正，可复制错误与代码交回 AI。App 不保证任意模型一次成功，也不将合法性检查称为美观或真实游戏校准检查。

支持多套命名方案、预览、编辑、复制代码与确认删除。新输入使旧校验失效；取消或保存失败保留原方案。预览读取当前遥测；没有收到数据时读数显示 `--`，不生成演示帧。用户的名称/文字不自动翻译，未内置中文字形使用系统回退。

## 协议与边界

根对象只有 `schemaVersion: 1`、`name`（1–60 字符）、`background` 和 `components`。固定 1280×540 画布，等比适配；颜色接受 `#RRGGBB` 或 `#AARRGGBB`。仅接受纯 JSON 或单个完整 JSON 代码块，不从说明文字中猜测抽取。

iPhone 横屏驾驶时，画布在安全区内等比放大，方案的底色铺至屏幕边缘。

每个组件必须包含 `type`、`x`、`y`、`width`、`height`，矩形必须完整位于画布内。数组顺序就是绘制顺序，允许重叠；画布与每个组件单独裁剪。隐藏组件留下原空间。最多 20 套，每套最多 128 个组件、64 KiB UTF-8、8 层 JSON 嵌套。

| type | 能力 |
| --- | --- |
| text / value | 静态文字 / 遥测读数，字号、颜色、对齐；读数单位由 App 格式化 |
| rect / line / circle | 圆角矩形、左上至右下直线、内接圆 |
| bar / arc | 直进度条 / 270° 圆弧，绑定 source；min/max，颜色、轨道色及弧线宽 |
| shiftLights | 20 灯、已标定换挡目标前 1500 RPM 起亮、到点蓝色 4 Hz 闪烁；未标定时灯暗 |
| tires / inputs | 四轮原始温度（强制 RAW / UNIT UNVERIFIED）、油门/刹车 |
| navigation | 复用现有局部路网、路线与车辆方向绘制 |

完整参数、默认值、数据源白名单和有效示例由 `CustomDashboard.components / geometry / sources` 生成，见 App「复制 AI 提示词」。校验器和提示词共用这些元数据；编辑器、设置读取、备份导入和保存共用校验器。未知属性、未知组件、非有限/越界数值、错误类型和非法数据源均拒绝。

车速始终服从 mph 开关。轮胎组件及直接绑定轮胎的数据服从 tires；踏板组和 throttle/brake/steer 绑定服从 inputs；navigation 服从 miniNav。RPM 条/弧范围仍使用当前帧 EngineMaxRpm（表盘量程），换挡灯单独使用 App 已标定目标：1–3 挡为限转估计减 750 RPM，4–10 挡减 500 RPM，未标定/倒挡/未知挡位不提示；无需升级 JSON 协议版本。无有效名次和计时用占位，不虚构胎压、水温、油温或圈速差。不允许外链图片、外部字体、表达式、脚本、文件读取或自定义按钮。

## 驾驶与赛事

五款自带仪表及自定义共用驾驶工具、录制、连接指示、横竖屏生命周期、全屏 Toast 与两秒长按恢复。全屏隐藏所有操作控件、消息和名次特效。手动选仪表不修改赛事目标。

设置页和驾驶页设置共用「进入赛事后切换仪表盘」：不切换 / 五款自带 / 每套自定义。下一次确认进入比赛时生效，记住赛前仪表并在确认赛事结束后恢复。赛事中手动切换视为接管，取消本场恢复；比赛中改变目标不立即切换。断流/暂停/回溯仍沿用原 RaceDetector，不据此直接判完赛。

删除正在使用的方案回基础；删除赛事目标改为不切换；被删除的赛前引用恢复为基础。删除弹窗说明影响。

## 保存与兼容

保留顶层 `version: 2`。settings 新增 `customDashboards: [{id, layout}]` 和 `raceDashboard: null | {kind: builtin|custom, id}`；kind=builtin 的 id 使用现有枚举名，custom 使用本地生成的方案 ID。新字段优先；旧 autoSwitch / raceStyle 继续读写，旧存档按原偏好推导赛事目标，方案列表为空。

备份包含全部方案；恢复是替换操作，旧备份恢复为空列表，恢复确认展示文件方案数。新备份交给旧版 App 恢复可能丢失新字段，不承诺旧程序保留自定义方案。新版本加载/导入均先整份校验，非法数据不部分替换；本地损坏继续阻止自动覆盖。保存/删除先通过既有串行队列完成原子写入，再公开新设置，写失败保留原方案。写入期间遥测和录制继续，之后刷新最新记录快照。

实现入口：`core/custom_dashboard.dart`、`widgets/custom_dashboard_canvas.dart`、`pages/custom_dashboard_editor.dart`；赛事协调和事务保存位于 AppController。回归入口 `test/custom_dashboard_test.dart`，既有连接弹窗/全屏/画布边界回归必须保留。测试与手机证据见开发交接最新章节，不代表真实 FH6 校准或 Profile 性能验收。
