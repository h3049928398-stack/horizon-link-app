# FH6 地图与导航

## 使用

地图拖动范围按方形底图的实际边缘限制，拖动、惯性滑动、跟随车辆、搜索居中及视口变化均受限。最小倍率随地图视口长宽比调整，使底图始终铺满可视区域；因此竖屏最小倍率不再同时展示整张方形底图，边缘地点的居中以不露出底图外空白为优先。

地图分类栏左侧新增「筛选地点」面板：支持多选类别、全选、清空，每类显示地点总数；点击「应用筛选」后地图标记、点击命中和搜索/浏览列表共用条件。返回或点击遮罩取消未应用的修改。按钮括号内为所选类别数；清空后隐藏全部地点标记，车辆与导航路线继续显示。搜索只在所选类别内匹配。底部页面切换保留筛选，重启应用恢复默认；快捷分类切换为单类，「全部」恢复原社区地点总览（搜索仍可查赛道），面板「全选」则显式包含赛道几何起点。筛选不改变地图视角或结束已有导航。

打开地图，点击「浏览地点」或搜索名称。选择地点后点击「导航到这里」。长按地图可以选择最近道路上的任意目的地。演示模式支持把选点设为起点，以及沿规划路线模拟行驶；真实模式从手机直接收到的 UDP 位置更新导航。所有符合当前类别与搜索条件的地点均逐个绘制，不进行数字聚合；点击重叠地点时通过列表选择具体地点。

点击攻略定位、地图标记（含重叠地点列表）或搜索/分类列表选点后，只显示选中地点标记，居中目标并把低于 3 倍的视角放大至 3 倍；已有更高倍率保留，重复定位不累积放大。取消选点恢复原筛选下的标记，隐藏标记不参与点击命中；车辆与已有路线保留。收起键盘后再按恢复的地图视口居中，边缘仍受底图不露空白的边界限制。分类或搜索地点列表展开后，点击列表之外的地图或页面区域即可关闭，关闭用的地图点击不会继续触发选点或地图按钮；搜索框和分类栏仍可继续操作。广告牌图案为带 XP 字样的横向牌面，地标为红白东京塔，吉祥物为三色团子；均为原创矢量图，地图、地点列表和选中卡片保持一致。

右侧提供四季切换、跟随车辆、查看全图。地图可拖动和双指缩放。地点使用带分类图标的定位针，尖端对应地点坐标；选中地点放大并高亮，导航道路接近点使用终点旗标。按用户最新要求，普通标记在地图缩小时变大、放大时变小：全图高度约 26 个逻辑像素，最大 14 倍约 24（从 20 稍微调大），连续平滑变化。点击范围独立保持至少 44×44 个逻辑像素，重叠地点通过列表选择。基础仪表中央显示前方路线缩略、转向提示和距离。演示定位初始位于原始路网第 0 个节点，演示速度与路线模拟各自独立。

道路叠层首次加载时异步生成 2048×2048 图像缓存；地点图标按类别预绘制，标记图层仅在倍率、视口或筛选条件变化时更新缓存，平移复用绘制记录。车辆与路线单独更新，路线几何只在路线对象变化时重建。拖动或无关遥测更新不再重新绘制整张原始路网、排版地点图标或排序全部地点。应用壳保留四栏页面状态，只更新可见页面，地图只响应地图相关状态变化。

导航中的地图默认锁定车辆箭头位置。拖动或双指缩放时暂停跟随，从手势结束开始等待 3 秒，再用 1 秒缓入缓出的动画回到车辆位置；逐动画帧读取最新车辆位置，保留用户缩放倍率，随后持续跟随。再次手势会取消等待或动画，松手后重新计时。导航中的选点、搜索定位及查看全图也暂时退出跟随，再按同一规则恢复；不在导航时，拖动后继续保持用户视角，原「跟随车辆」按钮可立即恢复跟随。边缘仍优先满足底图不露空白的既有边界，因此最靠近底图边缘时车辆可能无法完全居中。

切换底栏、路由不可见、进入后台、结束导航或销毁页面会取消自动回中等待/动画；返回可见地图且仍在导航时恢复跟随。应用壳用 TickerMode 标识可见底栏，保持四栏页面和缓存实例。所有定时与动画资源在销毁时释放；手机检查使用临时导航状态和实际触摸，未据此宣称完成真实游戏定位校准。

## 导航实现

Flutter/Dart 在手机本地执行 A*，搜索状态是有向路段，只走提取出的允许连接。起终点投影到路段，计算部分路段长度；目标的相反方向不会直接逆行到达。没有可用路线时显示失败，不退回穿越地形的直线。

100 米网格索引用于寻找附近道路。道路匹配考虑三维距离和由连续位置估计的行驶方向，减少高架桥与地面误匹配。持续偏离路线超过 55 米、持续 1.2 秒后重算，重算间隔至少 4 秒。静止帧不触发重算；非驾驶帧不更新导航。转弯提示根据道路段切换和前后 35 米的方向生成，属于应用自己的引导算法，不是游戏 ANNA 引擎。回溯后的新坐标会重新投影到路线，不锁死为单调前进；比赛遥测确认回溯后删除该时间及其后的旧样本，详见开发交接文档第 5 节。

车辆箭头使用 UDP 的 `Yaw`（世界空间车身朝向，弧度），与用于道路匹配的位移方向分别维护，倒车或漂移时不把移动方向当成车头。当前映射为零度朝世界 +Z（图上方）、正角朝 +X（图右方），通过 `atan2(sin(yaw), cos(yaw))` 归一化；可在静止/低速的有效驾驶帧更新。字段见 [FH6 官方 Data Out 说明](https://support.forza.net/hc/en-us/articles/51744149102611-Forza-Horizon-6-Data-Out-Documentation)，坐标约定另与参考项目 `static/app.js` 的直接 Yaw 旋转实现核对；仍需真实游戏校准。缺少 Yaw 的演示帧与旧记录使用位移方向回退，重新连接及切回演示清除旧定位/朝向。新采样保存可选 `yaw`，旧存档不补造零度或批量改写。

基础仪表简略导航采用车头朝上的视角：车辆箭头固定向上，以实际车辆位置为原点，把世界路线转换为相对车头的左右/前后坐标。仅路线随车身旋转，无路线时也显示固定向上的车辆标记；文字仍显示导航转弯指令。

简略导航现使用仪表设计坐标中的 220×108 窗口（原 180×72），箭头约放大 30%，路线略加粗。前方路线采样上限从 600 米延长至 1,200 米，采用每米 0.08 设计像素；实际可见范围仍受路线弯曲、车头朝向和窗口裁剪影响。箭头及提示文字下移，窗口上沿保持避开挡位区域，文字位于底部数据分隔线上方。

基础仪表右侧的导航图标可展开/收起「拓展导航」，原仪表设置开关已移除。默认关闭，仍通过既有 `expandedNav` 保存展开状态。开启时仪表按 0.74 等比缩小靠左，展开后隐藏右侧栏，收起按钮移到路网上方；移除标题、范围和目的地文字。右侧为 330×330 设计像素窗口，以实际车辆位置为中心、车头朝上显示 800×800 米正方形路网。没有游戏底图或地点标记，灰色显示窗口内全部提取道路，青色显示已有路线；无目的地也显示路网，无定位时等待。使用世界坐标米制投影和原有空间索引，不依赖底图对齐参数；保留穿过窗口但端点在外的道路。开启时替代左侧简洁导航，收起恢复原仪表内容；专业仪表不显示此入口。坐标/Yaw 仍待真实游戏校准。

## 已知范围

- 170 个点仅代表赛道文件中几何序列的首点。赛道名暂用 Route ID，不能等同已经核实的比赛报名触发点。
- 771 个坐标直接从公开网站的 35 个类别页面读取；车房 / 秘藏页面没有返回坐标，因此另外 24 个使用已有社区坐标来源。所有位置都保留 URL 并标为待实测。没有使用社区目录中的「道路代理位置」冒充收藏品位置。目标没有官方高度时，用邻近道路高度估计导航接近点；到达道路入口不代表已经拿到收藏品。
- 游戏数据库 `Stripped/gamedbRC.slt` 无 SQLite 明文头，未能直接读取完整地点表。地点层因此来自公开地图，未伪称为从数据库提取。
- 2026-10-28 从 `Stripped/StringTables/CHS.zip`、`EN.zip`、`CHT.zip` 只读解析内置名称，按同表 IDS/哈希配对。`Landmarks.str` 有 75 条地标名称；研究结果在 `artifacts/place-names/`。随后按用户要求接入独立的 `assets/map/place_names.json` 名称覆盖表：550 条现有地点记录匹配游戏中文名，200 条广告牌和 170 条赛道几何起点使用通用双语标签，45 条（含 24 个车房/秘藏车型原名）保留原名。没有把全部 861 条研究候选直接灌入 App。
- 名称按类别限制来源表，歧义时不猜测；少量经过核对的拼写/简称别名在 `scripts/prepare_place_names.py` 明确列出。覆盖表保留原英文、表名/IDS、别名标记及源 ZIP 哈希；`places.json` 的 ID、坐标、分类、来源及质量标签不变。游戏名称匹配不代表已核实社区地点坐标或 Route ID 对应关系。
- 默认中文，设置页可以切换 English 并本地保存；地图列表、重叠地点选择和导航卡片随语言显示名称，搜索同时接受中英文及地点 ID。尚未匹配的名称保留原拼写。重新生成覆盖表执行 `python scripts/prepare_place_names.py`，再运行字体脚本以包含新增汉字。
- 没有提取玩家已收集 / 已发现状态，没有接入云端服务。真实游戏 UDP 协议偏移仍需此前约定的实测校准。
- 已完成逻辑、资源与窄屏交互测试，安卓已验证地图加载、地点选择及本地路线规划；尚未做 FH6 实车路线比对、真机游戏位置更新导航或安卓/iOS 性能验收。
