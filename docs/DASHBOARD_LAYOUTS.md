## 选择与行为

- 仪表库新增三张实时预览卡片，点击后进入横屏沉浸驾驶页；顶部下箭头可在四款专业布局间切换，基础按钮随时返回基础仪表。退出恢复竖屏。
- GT 竞速：中央荧光黄挡位，左侧当前/最佳/上圈计时，右侧车速与名次/圈数。
- 耐力赛：青色分段弧形转速表，中央挡位与车速，右侧圈速对照；刻度按当前帧 maxRpm 绘制。
- 拉力赛：超大白色车速、橙色挡位、比赛计时与名次/圈数。
- 新布局共用底部轮胎原始温度、踏板、燃油、动力区。关闭轮胎或踏板时分别显示扭矩或增压。全部专业布局保留现有换挡灯时序和名次提升特效；隐藏、后台与销毁时停止闪烁计时器。
- `settings.raceStyle` 按枚举名称保存（professional/gt/endurance/rally）；缺键、未知值或 basic 回退原专业仪表。选择基础不覆盖偏好；自动比赛切换和「体验一场比赛」使用所选专业布局。

## 实现与数据边界

换挡灯使用自动标定的限转估计：同挡全油门三次有效反弹后，1–3 挡提前 750 RPM、4–10 挡提前 500 RPM 提示；以提示目标为终点，提前 1500 RPM 逐颗点亮，到点全蓝 4 Hz 闪烁。未标定时暂停提示，倒挡/未知挡位不提示。仪表设置显示学习状态和重新标定入口。`EngineMaxRpm` 只作表盘量程，不再当作限转或换挡目标；旧 `shiftRpm` 仅为 version 2 存档兼容保留。

`app_controller.dart` 管理布局与偏好；`dashboard_library.dart` 提供预览；`dashboard_screen.dart` 提供菜单和横竖屏生命周期；`dash_canvas.dart` 复用换挡灯，`race_layouts.dart` 为其 part，绘制三款新布局。界面文案提供中英文，仪表读数沿用赛车英文缩写。

只使用现有 TelemetryFrame 字段，不添加油温、水温、胎压、预计圈速或虚构的圈速差。无有效计时/名次时显示占位，轮胎温度保留 RAW / UNIT UNVERIFIED 标记。演示与合成数据的验证不代表真实 FH6 UDP、比赛识别或路线已校准。

回归入口：`flutter_app/test/dashboard_layouts_test.dart`，配合既有仪表、换挡灯、主题、连接弹窗等测试。设置 `RENDER_DASHBOARDS=1` 可将三款布局的真实字体 PNG 输出到 Git 忽略的 `artifacts/`，便于检查外观。

## 驾驶仪表保持亮屏（2026-11-20）

iOS 和 Android 在前台显示驾驶仪表时保持亮屏，覆盖普通、全屏及自定义仪表，即使在等待 UDP。驾驶工具的半透明弹窗保留仪表可见时的亮屏。退出驾驶、切到遥测记录或离开前台后，恢复使用设备的自动熄屏时间。回到前台且仪表可见时重新保持亮屏，手机的系统设置无需调整。实现及验收范围见交接第 86 节。
