# Horizon Link v0.3.0 · Android

这次更新加入驾驶仪表保持亮屏、按车辆学习换挡提示，以及设置内的版本检查。也首次将 JSON 自定义仪表、独立赛事仪表和启动与地图绘制优化纳入 Android 发布包。

## 更新内容

- 普通、全屏和自定义驾驶仪表在前台可见时保持亮屏。退出驾驶、打开遥测记录或切换到后台时恢复系统熄屏行为。
- 换挡灯按车辆及 PI 学习限转估计。尚未标定时灯带保持暗色，可在仪表设置查看状态和重新标定。
- 导入 JSON 可保存多套仪表布局。赛事仪表独立选择，赛事结束后通常恢复赛前布局。赛事期间手动换仪表时保留手动选择。
- 减少等待遥测时的界面刷新，路网和存档解析移到后台，改善启动、切页和地图拖动体验。
- 在「设置 → 关于与帮助」轻点底部版本号可手动检查更新。

## 下载与升级

- 需要 Android 7.0（API 24）或以上版本。应用包名为 `com.horizonlink.horizon_link`，版本为 `0.3.0`，构建号为 `3`。
- 下载 `Horizon-Link-v0.3.0-android.apk`。`SHA256SUMS.txt` 可用于核对 APK 是否完整。
- 从 `v0.2.0` 调试预发布迁移时，请先在「设置 → 数据备份与恢复」导出 JSON，并确认备份可读取。两个版本的签名不同，Android 无法直接覆盖安装。完成备份验证后再迁移并导入数据。

## 使用提示

在 FH6 中启用 Data Out，目标 IP 填手机的局域网地址，端口与 App 保持一致，默认为 `8000`。首次启动和政策更新后，请阅读 App 内的隐私说明。

已使用游戏实时遥测验证收包和部分车辆的换挡学习。部分工况会得出偏低的限转估计，地图坐标和赛事状态识别仍在验证中。
