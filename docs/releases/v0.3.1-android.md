# Horizon Link v0.3.1 · Android

「设置 → 关于与隐私」中的「开发者」默认折叠。点击可展开查看姓名，再次点击可收起。简体中文和 English 界面均支持此操作。

## 下载与升级

- 下载 `Horizon-Link-v0.3.1-android.apk`。需要 Android 7.0（API 24）或以上版本，构建号为 `4`。`SHA256SUMS.txt` 可用于核对安装包。
- 已安装 v0.3.0 正式版的用户可直接覆盖安装。若从 v0.2.0 调试版迁移，请先在「设置 → 数据备份与恢复」导出并验证备份。
